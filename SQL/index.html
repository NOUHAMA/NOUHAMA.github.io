dbt Analytics Pipeline

End-to-End Data Transformation on Superstore Dataset

This project builds a modern data pipeline using Snowflake and dbt to transform the Superstore dataset into a clean, scalable analytics layer. It covers data ingestion, transformation, testing, and modeling, delivering business insights across finance, customers, products, and operations.

Project Goal

The goal of this project is to transform the Superstore dataset from Kaggle into a structured analytics warehouse using dbt.

  • Ensure data quality with testing and validation
  • Build reusable transformation layers
  • Deliver business-ready analytics models
📌 Add Dataset Schema Screenshot

Data Model & Architecture

The data model follows a star schema centered around a sales fact table, connected to customer, product, order, and geography dimensions.

Pipeline Overview

The pipeline follows a modern analytics architecture:

  • Data ingestion into Snowflake
  • Transformation with dbt (staging → intermediate → marts)
  • Data quality checks and testing
  • Business-ready analytics outputs
