❄️ Snowflake Ingestion

This stage focuses on loading the raw Superstore dataset into Snowflake as the foundation of the analytics pipeline.

What I Did

  • Created a Snowflake database and schema for raw data
  • Loaded the Superstore CSV dataset into Snowflake
  • Prepared raw source tables for dbt transformations
  • Separated raw data from transformed analytics layers

Goal

The goal was to centralize the raw dataset in a scalable cloud warehouse before applying transformations with dbt.

Tools Used

  • Snowflake
  • SQL
  • Superstore Dataset
